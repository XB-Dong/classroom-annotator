## Docker 与跨环境部署

云端已经实际使用 Docker Compose，五项服务为 Go/FFmpeg 后端、Nginx 前端、Prometheus、Grafana 和 node-exporter；当前应用 SHA 为 `f2d6d083efc0a7e8d3668f2593b0b22c3614c99b`。AI 服务尚未启动。

当前发布流程面向 Ubuntu / linux-amd64：Go Linux 二进制与 Vite dist 预先构建，Dockerfile 复制构建产物；Compose 使用本地已加载镜像、`pull_policy: never` 和手动创建的外部卷。并非新机器克隆后直接 `docker compose up` 就能完成部署。

Windows 具备 Docker CLI，但当前 Docker Desktop 引擎未运行，未在此次启动；此前实际验证的是 Windows 原生后端处理真实素材。Mac 没有实际部署验证。Windows/Intel Mac 可通过 Docker Desktop 的 Linux 容器承载应用；Apple Silicon 还需匹配 arm64 镜像/Go 二进制或使用 amd64 仿真，不能将不匹配的架构混装。参考 [Docker 多平台构建](https://docs.docker.com/build/building/multi-platform/)。现有 node-exporter Linux 主机挂载在桌面环境采集的是 Docker Linux VM，不能当作原生 Windows/Mac 主机监控。
