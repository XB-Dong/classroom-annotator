## Docker 与可移植性

Docker Compose 已实际承载云端的 Go/FFmpeg、Nginx、Prometheus、Grafana、node-exporter。当前发布流程面向 Linux amd64，需要预构建产物、镜像准备、外部环境与数据卷，尚不能承诺 Windows/Mac 新克隆后一键部署。Windows Docker 引擎当前未启动，Mac 未实际部署；Apple Silicon 需 arm64 匹配构建或 amd64 仿真，见 [Docker 多平台说明](https://docs.docker.com/build/building/multi-platform/)。桌面 node-exporter 采集的是 Docker Linux VM，不能冒充原生 Windows/Mac 指标。

跨平台多阶段构建、amd64/arm64 镜像与初始化入口作为后续部署完善事项，本次未自动实施。GLM 独立审核继续只能针对可分享代码或独立合成环境，不能使用这台包含真实媒体的实例及其凭证。原始证据保存于仓库外 `runtime/p0-followup/`。
