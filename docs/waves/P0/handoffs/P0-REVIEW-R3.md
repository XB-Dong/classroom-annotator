## Backend：Astra 审核

审核提交：`a4b7b1d22b96e9d80781cb37e636992b166e6128`。独立上下文，`gpt-6-astra / xhigh`。正常路径测试和 vet 通过，但独立复现四项问题；全部采纳，已派发 Backend 第一次修复。

1. Windows 锁住暂存 JPEG 后取消，删除失败被忽略，任务仍报告 cancelled；需要传播清理失败，避免成功取消状态与残留不一致。
2. HTTP 自定义方法直接进入指标标签，产生无界序列；需要固定方法枚举及 other。
3. FFmpeg 9.0.2 的尾部请求因 MJPEG 像素格式初始化失败返回 EXTRACTION_FAILED；精确命令增加输出像素格式后可进入规定的 FRAME_UNAVAILABLE 路径。现有测试是真实 Red，先前云端 FFmpeg 4.4.2 通过证据仍有效。
4. 上传的超时晚于 multipart 解析，且不能中断阻塞读；真实 HTTP 慢请求在配置期限后仍持有暂存文件。需要在读取前设置可中断期限并验证清理。

审核确认现有事务发布、独立批次、取消与完成竞争、启动回收、私网目的校验、重定向及凭证隔离有对应实现和测试，不需要推翻架构。
