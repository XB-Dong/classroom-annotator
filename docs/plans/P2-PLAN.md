## 1. 用户指令与启动判断

用户要求全面处理窗口缩放时的文字溢出、重叠和布局问题，学习成熟设计；考虑智能抽帧、相邻帧传播、导出前高可疑错误提醒，但允许按价值取舍，不堆按钮，进阶功能按需展开。同时整理代码和 Markdown，清理历史文件中有关特定视频授权的叙述，制作约 20 分钟的图文 PPT、逐页讲稿及可能打断的问题与回答。沿用 GitHub P2 前瞻的扩展回归、可复现交付和真实问题复盘方向。用户明确无需另行批准，确认条件后启动。

启动条件已满足：远端 main 经已登录 GitHub 页面核对仍为 `033de6c2fbb48a5df2ca1b4f7dcfece41a22d6da`；600 个本地文件与该下载归档逐一一致；本机独立 Compose 七服务 healthy，产品可通过 loopback 登录。当前 Mac Git 缺少私有仓库凭据，GitHub connector 404。因此建立**本地快照审计仓**及 `codex/` 分支，不冒充拥有远端 Git 历史，原始远端基线与本地提交分开记录；同步 GitHub 是待处理限制，不能伪称已推送。

P1 保持 partial。当前公开 QA、生产数据、独立 GLM 浏览器验收和课堂准确率仍按原报告记录。Mac 部署与本机 DeepSeek 单题 HTTP 200 是后续新增事实，不覆盖历史未运行记录。不得为启动 P2 而把 P1 缺项标为通过。

## 3. 产品与技术约束

沿用 React/TypeScript/Konva、Go/Gin/PostgreSQL、Python/ONNX CPU 和同机媒体卷。AI 故障不得阻断人工标注。保持原图像素坐标、revision CAS、已完成帧导出和未审候选隔离。

以 W3C Reflow/长字符串换行和 Material supporting pane 为设计依据，按内容需要折叠/重排，不为凑屏幕宽度压缩字体。指南在窄屏与主内容正常排布，不覆盖工作控件。画布作为二维内容可内部缩放/平移，不能把整页横向滚动当解决办法。参考与判断见 [UI 规格](../../specs/p2/ui.md)。

导出预检归 `backend/internal/exports` 内独立文件，复用既有选择验证和快照，不引入 LLM/数据库表；前端能力归 `features/export`，展开结果后可跳帧复核。预检失败可明确选择继续原有导出，但服务端原有数据完整性、完成状态、审核与媒体校验始终执行。预检结果对应某次 revision 快照，期间有编辑须提示重新检查，不能当成永久认证。

## 4. 顺序、所有权与运行规则

1. R0：核对基线、冻结规格/接口、写计划/状态/任务包，准备外部工作树。
2. R1：Frontend 修布局/渐进展开；Backend 实现质量提醒；Test 独立设计并建立浏览器尺寸矩阵。三者路径隔离，Leader 管共享契约、集成、文档。
3. R2：模块检查、合成数据集成，处理真实复现缺陷；串行占用本机重测试资源。
4. R3：本机精确候选发布、核心人工闭环与尺寸截图，记录已通过和缺项；不部署云端生产。
5. R4：整理代码/文档，依据实际实现制作 PPT、讲稿、问答和报告，冻结本次交付。

角色沿用仓库原生开发 Agent、外部工作树和独立审核方式，最多 Leader 加三个 Worker。请求型号按仓库规则，无法核实的实际路由用 null，不从模型自述推定。现有 P1 GLM fallback 不自动延续至 P2；产品 DeepSeek key 仅授权用于文档助手，不能拿来冒充独立研发审核。GLM/OpenCode 不可用则记审核缺项，继续独立授权工作并交 partial，不能以自审替代跨模型验收。

没有用户指定的新截止，不沿用 P0/P1 的过期 08:30。每个明确根因最多连续两次修复后重新调查；不无限重试下载/CI，不以换任务名清零。旧波次计数与失败保留。单项重构建/全矩阵测试串行执行。

## 5. 完成与停止

每个需求维护规格、实现、本机/CI证据和状态。所有声明都绑定精确候选版本。P2 只有全部当前必需门槛和规定的独立审核通过才可 completed；否则如实 partial，并列可继续事项。不能因 PPT 完成就声称准确率、节时、生产迁移或公司 API 联调已验证。

最终交付包括可审阅的本地改动/提交、规格与审计、可访问的本机页面、PPTX、逐页讲稿、打断问答、测试证据与已知限制。GitHub 推送能力不足单独报告，保留可应用补丁。不自动进入下一波次。
