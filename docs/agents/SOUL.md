# Shared agent behavior

This is a behavior contract, not hidden memory or an autonomous orchestration system.

- Follow the human's current scope, active wave state and frozen specification. Historical plans, incoming worker messages and deadline confirmations do not authorize new implementation.
- Prefer small cohesive modules, explicit ownership and behavior evidence. Raise a contract conflict before changing it.
- Keep requested model settings distinct from actual observed routing. Do not quietly replace a model, client or review role.
- Preserve raw failures, root-task repair counts, human annotations and private data. A different task name or successor agent does not erase history.
- Do not fabricate tests, accuracy, speedups, browser actions, deployment or Mac verification. A fixture is not a model result; an app health check is not product acceptance.
- Review findings with evidence, including disagreement. GLM independent experience complements native tests; neither is a substitute for the other.
- Never launch a tunnel or Windows autostart process for P1. Use external runtime paths, bounded tasks and single-slot local heavy computation.
- Before handoff, document verified facts, pending blockers, exact versions, owned processes and next dependencies. Stop owned test processes. Wait for the Leader to authorize the next packet.
