# Internal head detection service

The Go backend is the only caller. The service accepts image bytes, never media URLs, paths, business credentials, account cookies or database connections. Model weights are external and mounted read-only. Use the exact artifact described in `model-manifest.json` and retain `MODEL-LICENSE` with distributions.

Python3.12 is supported. Install `requirements.lock` with `pip install --require-hashes -r requirements.lock`, then set `PYTHONPATH=src`. Run `uvicorn classroom_ai.app:create_app --factory --host 0.0.0.0 --port 8090 --workers 1 --no-access-log` with `AI_MODEL_PATH` and a secret `AI_INTERNAL_TOKEN`. Keep the network private to Go; do not publish8090. The prepared Dockerfile belongs to Leader integration and is not a claim of a tested image or deployment.

`POST /v1/detections` requires `Authorization: Bearer <internal token>` and multipart fields `image`, `confidenceThreshold` (default0.25), `nmsThreshold` (default0.50). `X-Request-ID` is safely echoed; absent or invalid IDs are replaced. JPEG/PNG must be at most15MiB and16 megapixels. The entire HTTP body is bounded before multipart parsing, and file spooling remains in memory. Invalid bytes/numbers return422, missing auth401, busy429, unavailable model503, deadline504. Errors contain only safe code/message/requestId. Liveness and readiness are separate.

Input is RGB float32[0,1], letterboxed to640 with actual rounded scale/padding preserved. Head=7 is an independent class score, not an argmax over Body/Face/head-direction subclasses. Scores and boxes must be finite and valid. Output bbox is original-image `[x,y,width,height]`, bounded to the image. `clipped` identifies pre-clipping bounds; `tileBoundary` marks internal crop boundaries for explicit human review.

Pipeline version is `classroom-head-v1-fullframe-2x2-15`. When max original dimension is at least1280, the same Nano runs once on the full frame and once on each of four15%-overlapping tiles, then global NMS merges duplicates. Smaller images run once. The single inference slot spans decoding and all five calls; CPU ORT uses one thread with spinning disabled. A30s timeout discards late results, requests native termination, and retains the slot until the worker actually ends. Cancellation cannot promise to kill a hung native thread. Process readiness must be monitored externally.

Run `python -m pytest tests -q`. Default real-model tests skip unless `AI_TEST_MODEL_PATH` and `AI_TEST_SAMPLE_DIRECTORY` are configured. Skips mean `not_run`. Authorized private sample pixels, arrays and overlays must stay external and must never enter Git or GLM. Unit fixtures prove geometry/output validation only; they do not prove model quality. Real-image evidence has substantial missed heads; candidates require manual review and supplementation.
