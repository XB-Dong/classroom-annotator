# Business API contract

Version: 1.1.0 (P0.1 four-source and safe company DTO additions; P0 historical versions 1.0.0/1.0.1). Prefix /api/v1. JSON fields camelCase; no envelope except list collections. Error {code,message,requestId}. Dates ISO8601 offset/UTC. IDs strings. No AI routes P0.

GET /videos ->200 {videos:Video[]}; POST /videos multipart field file ->201 Video{id,name,width,height,durationSeconds,status,createdAt}.
POST /videos/{id}/extractions JSON {intervalSeconds,startSeconds?:0,endSeconds?} ->202 Job{id,kind,videoId?,batchId?,status,progress,error?,createdAt}. kind extraction always has videoId and batchId; kind import has videoId only after success and no batchId. Status queued|running|cancelling|completed|failed|cancelled. GET /jobs ->200 {jobs:Job[]} returns newest100; GET /jobs/{id} ->200 Job. POST /jobs/{id}/cancel ->200 Job (existing terminal returned unchanged; running may return cancelling).
GET /videos/{id}/batches ->200 {batches:[{id,videoId,jobId,createdAt,frameCount}]} completed batches newest first. GET /videos/{id}/frames ->200 {frames:Frame[]}; optional batchId query restricts, invalid ownership404. Frame{id,videoId,batchId,timestampMs,width,height,imageUrl,status,revision}; imageUrl relative /media/frames/{id}.jpg accessible same origin; timestampMs is sampling target, not source PTS.
GET /frames/{id}/annotations ->200 Snapshot{frameId,revision,status,annotations:Annotation[]}. PUT same resource body {expectedRevision,status,annotations}, returns200 Snapshot. Annotation{id,bbox:[number,number,number,number],source:'manual'}. Frame status not_started|in_progress|completed. Missing/source optional? source required in writes; require all fields. On malformed input400, invalid geometry422, absent404, stale revision409; no write on failure.
GET /videos/{id}/progress?batchId=optional ->200 {total,notStarted,inProgress,completed}. POST /exports JSON {videoId:string,batchId?:string} OR {frameIds:string[]} ->200 application/zip; selectors cannot mix. Selected completed frames only, zero-head completed legal; no exportable frames422. Stage and close ZIP before response headers; consistent DB read snapshot and immutable image files.
GET /dataset/lessons?page=1&pageSize=50 ->200 observed shape {type:string,items:DatasetLesson[],total:integer,stats:object}; upstream snake_case is an explicit exception to business camelCase. Observed consumed lesson fields id:integer,course_name:string,organization_name:string,teacher:string,date:string,section_index:integer,videos:DatasetVideo[]. Optional observed name/room/start_time/end_time may be string or null. DatasetVideo{id:integer,lesson_id:integer,catalog_file_id:integer,channel:integer,part_index:integer,tags:object}; preserve channel fields and UI lists only channel4. Business import converts catalog_file_id to decimal string; backend validates consumed upstream id/lesson_id/catalog_file_id are nonnegative integral JSON values <=9007199254740991 before returning numeric DTOs; otherwise502 DATASET_INVALID_RESPONSE. Do not round through unsafe JS integer IDs. Missing config503 DATASET_NOT_CONFIGURED. POST /dataset/imports {catalogFileId:string,name?:string} ->202 Job(kind import,videoId absent until import completes). Remaining upstream fields may be preserved but not guessed/required by UI. Use synthetic values matching observed shapes, never copy personal metadata.
Health outside prefix: GET /health/live, /health/ready ->200 {status:'ok',version:string}. GET /metrics Prometheus. Import/extraction Job GET exposes resulting videoId once successful. Max lengths/size from config. ZIP errors occur before headers; no physical paths or secrets in responses.

Observed upstream routing/config: APP_DATASET_API_URL origin plus APP_DATASET_ID; GET /api/v1/datasets/{datasetId}/lessons?page=1&page_size=50 uses X-API-Key. Playback GET /api/v1/catalog-files/{catalogFileId}/play-url on same configured API origin. Missing API/dataset config503 DATASET_NOT_CONFIGURED. Provided dataset13 is configurable, never embedded as an implementation default. See decision0005 for material-derived correction.

P0.1 storage: Video additionally requires sourceKind(public_sample|upload|mac|dataset|legacy) and storageProvider(local|mac). Public samples are local; upload/mac/dataset are Mac. POST /videos streams the browser upload to Mac, never falls back to cloud disk. Public source URLs/files are not accepted from the browser.
GET /samples -> {items:PublicSample[]}; availability ready|unavailable. POST /samples/imports {sampleId} ->201 new Video or200 existing identical Video, preserving annotations. GET /media-sources/mac?cursor -> {contractVersion:'1.0.0',items:MacSource[],nextCursor:null|string}; sourceId is an opaque stable identity, distinct from the legacy whitelist id. POST /media-sources/mac/imports {sourceId} ->202 Job. GET /media-storage/status -> {providers:[{provider,available,reasonCode}],sources:[{sourceKind,available,reasonCode}]}, reasonCode nullable. Media availability does not control database readiness.
P0.1 company projection returns only type/items/total and the specified lesson/video fields. No arbitrary stats/tags, raw errors or playback/source URLs cross the bridge. Browser pageSize maps explicitly to bridge page_size and the observed upstream page_size. The company key stays on Mac.
Cross-frame annotation ID reuse returns400 ANNOTATION_ID_COLLISION with no partial write. Runtime database/schema unavailability returns503 NOT_READY on readiness; an unsupported schema fails server startup. Mixed storage providers in export return422 MIXED_MEDIA_PROVIDERS; separate exports are required. Mac ZIP is completed remotely before streaming, with no cloud ZIP file. Public sample ZIP includes credits.json and LICENSES.txt per specs/p0.1/public-sample-contract.md.
