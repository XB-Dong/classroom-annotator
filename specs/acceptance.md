# P0 验收规格

版本：1.0.0｜状态：已冻结，Astra审核通过

验收ID沿用P0-PLAN.md现行14项，使用本地/合成材料；真实公司API未运行标not_run，不阻塞P0。最低检查：

- P0-BASE-001：配置失败即退出；迁移可重复；统一构建/测试脚本；备份恢复说明能复做。
- P0-VID-001：上传合成视频返回尺寸/时长；损坏/超限/路径名不会留下未管理媒体。
- P0-VID-002A：合成API符合已观察schema；分页、channel4选择、play-url获取、下载成功；媒体端不得收到API key，失败安全反馈。
- P0-FRM-001/JOB-001：固定区间数量/目标时间/尺寸；新batch不覆盖旧；排队/取消/超时/失败/重启状态与清理。
- P0-ANN-001：四种框编辑与缩放坐标；非法/重复ID/非有限/越界框拒绝。
- P0-SAVE-001：GET/PUT一致，旧revision409与事务不改变；刷新与后端重启保存可见；草稿恢复冲突显式处理。
- P0-PROG-001：显式完成/撤销完成/零人头与进度一致。
- P0-EXP-001：独立读取ZIP/JSON校验IDs、关联、尺寸、area、坐标、图片字节；未完成排除。
- P0-OPS-001/OBS-001：部署实际SHA；持久化/恢复；Prometheus targets与Grafana数据源/dashboard指标。
- P0-E2E-001：浏览器上传→抽帧→框绘制/编辑→保存→刷新→完成→ZIP导出。
- P0-AUD-001/REV-001：实际TDD命令/时间/退出码/提交追踪；智谱独立代码审核和实际产品浏览器体验；Leader逐项处置。

错误路径和安装错误分开，安装失败不算TDD Red。红绿证据由各任务生成者写入独立文件，Leader只索引不改造。云端用合成视频，授权本地样本只在Windows检查。
