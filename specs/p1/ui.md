# P1视觉与交互规格

版本：0.1.0｜待审核；批准前不修改产品页面。

## 1. 设计原则与具体布局

“课堂手账工作台”：亲切的纸张/墨线感，功能区稳定且密度适中。主体白色、页面暖灰；正文深墨，蓝色用于主操作，赭黄用于待复核，绿色完成，红色失败。色值统一token，避免分散硬编码。

```text
┌ 标注工作台    工作区 / 视频 / 批次       保存状态     账号 ┐
│ 素材与帧       精确图片画布             审核面板          │
│ 示例/上传      选择 画框 撤销 重做      待审/高风险筛选   │
│ 图片缩略图     原始视频抽帧             原因+定位+决策    │
│ 完成/可疑标记  可缩放平移，不加特效     完成图片 / 导出   │
└ 进度条与操作提示             AI进度 / 故障 / 冲突提示    ┘
```

桌面三栏约240px / 自适应 / 300px；1280×720上中央仍有可操作画布且底部按钮可访问。1024px以下右栏可折叠，缩略图横向显示；360px可查看任务和审核列表，不声称手机适合精细画框。

外壳：轻微不规则边框、2–4px偏移阴影、少量自绘SVG图标/空状态插画。按钮本身点击区稳定，不旋转整个控制器；每个页面最多一处装饰插画，不能抢占画布。

正常无衬线正文；标题可用系统字体加少量手写形态SVG字饰，不下载大型中文手写字体。数字和置信度使用等宽数字。正文不低于14px，触控/常用按钮区域至少40px；普通文本对比度目标4.5:1。遵守减少动画偏好，无背景循环动画。

## 2. 页面与状态

- 注册/登录：清晰用户名、密码、邀请码字段，显示安全错误和加载；不把验证码/邮箱找回当已实现。
- 首页：公开示例卡片有真实缩略图/出处，授权视频在已登录素材区，不混同公开素材。
- 工作台：始终可见当前账号、视频、批次、帧号、保存状态、AI是否运行；不得把未保存当“已保存”。
- 复核面板：点击某条框定位并高亮画布，显示可读风险原因；图片风险可筛选后跳转。
- 候选虚线、正式框实线；需复核黄色+警示文字，选中蓝色+明显控制点。框不抖动、不故意画歪。
- 常用操作支持键盘，输入框内不触发删框/切帧快捷键，焦点可见。
- 冲突反馈阻止继续自动保存，可查看最新版本并保留本账号草稿；不出现含糊“保存成功”或强制覆盖按钮。
- 未配置公司API、AI离线、模型加载失败、空批次、推理未检出、全部拒绝、显式零人头均有独立准确状态。

## 3. 图表与统计

用小型比例条/数字卡表达审核进度、可疑图片/框、无需调整通过率、修改/拒绝/补框数量；说明分母与“未评估”。不增加装饰性大仪表盘，不把置信度画成识别成功率。

## 4. 文件边界与验收

复用 `frontend/src/features/annotation/{Canvas,Editor,FramePicker,saveController}.tsx/ts` 与 videos/export能力；新增 `features/auth/`、`features/review/`，主题集中 `shared/ui/`。拆分过重Editor职责，不为了换皮重写坐标算法。

验收：1440×900、1280×720、窄屏各真实截图；画框、移动、resize、撤销、快捷键、保存刷新、风险定位与冲突均可用。截图没有原始素材授权时只用公开/合成图片；不要以视觉截图代替功能E2E。
