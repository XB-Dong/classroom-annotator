# P2 提效选项取舍

版本：0.1.0

## 智能抽帧（P2-SMART-001，本轮不实施）

目标是减少重复标注图片，不以少抽出的数量直接衡量效果。固定间隔保留默认行为，新模式需明确称为“相似帧筛选”，记录算法/阈值/每个保留时间戳及跳过原因，独立批次保留原标注。精确哈希去重只能处理完全相同画面，不能称为课堂内容理解。

场景变化对静态机位课堂可能过度删帧。后续设计应在固定间隔候选中做有界相似度筛选，强制最长保留间隔、首尾/最少样本和可回看被筛帧；测试微小人头移动、低光、遮挡、切镜头、相机抖动、取消/重启。比较工作量和漏掉变化的比例必须有人工对照。本轮没有校准集与真实效果证据，因此先不增加一个容易误用的新按钮。

## 相邻帧传播（P2-PROP-001，本轮不实施）

传播只能产生可撤销的待审候选，目标帧既有人工标注不覆盖。要求同一视频/抽帧批次、相邻有效时间、尺寸相同；冻结源和目标 revision，任一变化返回冲突。记录 sourceFrame/sourceAnnotation/sourceRevision/algorithmVersion，不把传播冒充 ONNX 检出或无调整接受。

简单复制坐标会在学生移动/遮挡时产生误标，光流/跟踪又引入校准和失败分支。需先给出运动/遮挡/双端并发/刷新/撤销/导出隔离测试，再决定是否单独开发。本轮不改 source 枚举或候选数据库结构。
