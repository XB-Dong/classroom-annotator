## 4. 如何判定完成

- `completed`：本表所有门槛通过，真实 Mac 已授权样本联调通过，独立 GLM 两项门槛通过，部署和恢复可复现。
- `partial`：例如 DB 已验收而 Mac/GLM 阻塞；明确可用功能、已发布变化、未过门槛和后续动作。
- `blocked`：在实际任务状态记录关键依赖阻塞，不借此清空失败计数；时间/预算到达仍报告并停止。
- `realApiVerificationStatus=not_run`：公司真实 API 未试验，单独事实记录，不阻塞本波次；不要把 Mac 本地资源链路冒充公司 API。
- `simulated`/`not_run`/`failed`/`timeout` 不能填 `passed`。mac 仅 synthetic 通过时仍不满足实际 Mac 门槛。

报告须区分 P0 原版本、仅数据库迁移版本、P0.1 最终版本；媒体端离线不意味着云端数据库 ready 应失败，反之数据库故障不应显示“全部健康”。
