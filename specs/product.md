# P0 产品规格

版本：1.0.0｜状态：已冻结，Astra审核通过

单使用者标注学生可见人头。入口依次为视频库、抽帧批次、标注工作台、进度和导出。UI 使用中文，源码/契约英文。上传本地视频，展示名称/尺寸/时长与任务状态。抽帧间隔为正数秒，选择视频时间区间；重抽帧建立独立批次，旧帧/标注不覆盖。

工作台展示原图、画框/选中移动/调整/删除、图片切换、标注列表与数量、完成标记、保存状态。缩放画布不改变原图坐标。Delete 删除选中框；Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做；输入控件聚焦时不触发删除/导航。上一帧框复制可作为省时交互，但不得覆盖已有未保存工作。零人头需用户显式标记完成。

编辑约500ms后串行自动保存，一次发送捕获的snapshot和editSequence；成功只确认该次快照，期间新增编辑必须保留并继续保存，只有当前序号匹配ack才清理草稿。保存失败/冲突有可见提示，冲突解决期间暂停autosave，未保存时不得声称成功。刷新可从浏览器草稿恢复；草稿基准revision不一致时显式选择，替换服务器内容也必须使用最新revision。只有已完成帧进入选定范围 COCO 图片 ZIP。AI 预标注不属于 P0。

公司数据入口使用材料驱动的真实可配置适配器；未配置 API 时清晰提示，不伪造远程列表。实际公司环境不作为 P0 门槛。Windows 本地授权课堂媒体不进入 GitHub/云/第三方模型；公开与云端验收使用合成课堂图像/视频。
